## ✨ Features

### 👤 Citizen Features

- 📍 **Report Civic Issues**
  - Submit an issue with description, category and location.

- 📸 **Photo Evidence**
  - Upload images of the civic problem.

- 🗺️ **Interactive Issue Map**
  - View reported problems directly on a map.

- 📌 **Location Detection**
  - Select a location manually or use the current location.

- 🕵️ **Anonymous Reporting**
  - Report issues without revealing your identity.

- 📊 **Track Reports**
  - Follow the progress of submitted reports.

- 🔴 **Live Issues**
  - See active civic problems around Delhi.

- 👍 **Community Support**
  - Support/upvote problems affecting multiple people.

- 🤖 **AI-Powered Analysis**
  - Analyse reports and estimate issue severity.

- 🔗 **QR-Based Reporting**
  - Quickly access the reporting system through QR codes.

--

## 🏛️ Authority Access

KOINOS also provides a dedicated authority interface.

Authorities can:

- View submitted civic reports
- See the exact location of problems
- View uploaded evidence
- Check issue severity
- Monitor report status
