==================================================
2. MOST IMPORTANT UX GOAL
==================================================

KOINOS must be usable by:

- a teenager
- a senior citizen
- someone who is not tech-savvy
- someone using a phone for the first time
- someone with limited English
- someone who simply wants to report a pothole in 20 seconds

If someone opens KOINOS and asks:

"Where do I report something?"

The answer must be visually obvious within 2 seconds.

The primary action everywhere should be:

REPORT AN ISSUE

Do NOT make users understand the entire system before they can report something.

Progressive disclosure:
Show only what the user needs at that moment.

4. KOINOS VISUAL IDENTITY
==================================================

Create a distinctive visual language.

Primary direction:

Warm off-white / paper-like background
+
near-black typography
+
one strong signature accent color
+
occasional dark sections

Use the accent consistently for:
- Report button

- progress
- important statistics
- AI highlights
- community actions

Use color sparingly.

The interface should still look excellent in grayscale.

==================================================
15. ANIMATION
==================================================

Use animation to communicate meaning.

GOOD:

Reports merging into one issue
Priority number increasing
Status timeline advancing
Map markers appearing
Before/after slider
Community count changing
Civic health score improving

BAD:

Random floating blobs
Excessive parallax
Spinning icons
Animation everywhere
Slow page transitions

The site should feel alive, not distracting.
